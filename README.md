# homebrew-parcad

The Homebrew tap for [ParCAD](https://github.com/ierehon1905/parcad).

```bash
brew tap ierehon1905/parcad
brew install --cask parcad
```

Builds are unsigned, so a manual download makes macOS call the app *damaged*.
Homebrew clears the quarantine flag as it installs, which is the point of the tap.
